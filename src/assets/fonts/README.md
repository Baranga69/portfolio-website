# Fonts

Generated by `scripts/build-fonts.py`. **Do not hand-edit the `.woff2` files** —
regenerate them instead, or your change will be silently overwritten.

Both families are licensed under the SIL Open Font License 1.1, whose terms
follow these files into any distribution of this site. The copies here are
*modified* under §2 of that licence: subsetted to the codepoints this page
renders, with the `wght` axis narrowed and `opsz` pinned on the italic. They are
not suitable for reuse as general-purpose webfonts — get the originals instead.

| Family | Copyright | Source | Licence |
| --- | --- | --- | --- |
| Newsreader | 2020 The Newsreader Project Authors | <https://github.com/productiontype/Newsreader> | `OFL-Newsreader.txt` |
| Archivo | 2020 The Archivo Project Authors | <https://github.com/Omnibus-Type/Archivo> | `OFL-Archivo.txt` |

Neither family's Reserved Font Name is used: the CSS references them through
Astro-generated hashed family names (`Newsreader-<hash>`), so the subsets are
never presented to a browser under the bare original name.

`manifest.json` records what each file contains — weight range, style, declared
`unicode-range`, and the variable axes that survived subsetting.
